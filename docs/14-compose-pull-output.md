# 编排更新镜像的实时命令输出

“更新镜像”只执行固定docker compose pull，不执行up、不自动重建运行中容器。确认后弹出任务窗口，显示服务器返回的实际命令与标准输出/错误输出，最终显示任务状态和退出码。

实现采用异步启动与每秒增量游标读取，而不是等待同步HTTP请求结束才显示整段日志。输出仅在进程实际写出后出现：项目锁排队、下载器缓冲或网络等待期间可以没有新行，不能填充虚假进度。

## 权限与安全

- 启动与读取都需要该服务器operate权限，配置管理权限不因此下放。
- 只执行白名单固定命令，不支持任意命令输入，不通过shell解释。
- 请求正文只包含幂等请求标识，任务输出不写入审计。审计记录“提交拉取任务”，不把HTTP202受理当作镜像更新成功。
- 日志经Agent脱敏后返回；浏览器仅按文本展示，禁止HTML解释。输出缓冲、任务数量和保留时间均有上限。
- 返回结果禁止缓存，游标只返回新增内容，截断必须明确提示。

## 中断与重试

关闭窗口或网络中断不会取消已接受的任务，重开窗口继续读取；发起请求结果不明确时，使用同一request_id重试确认，不能生成新任务冒险重复执行。断线不等于执行失败或成功，最终结果必须由Agent任务状态确定。Agent进程重启后临时任务记录可能丢失，界面应明确无法读取而非猜测成功。
