# 卷内文件管理

本批已部署到243进行独立卷验收。以下记录区分真实API验证、浏览器验证和未覆盖项。

## 入口与功能

点击服务器存储卷列表中的卷名，进入独立文件管理页面。支持目录浏览、面包屑、当前目录名称过滤、读取文本、编辑保存、新建文件和文件夹、上传、下载、重命名、删除文件及空文件夹。

首批单文件上限4MiB，目录最多2000项，超限明确拒绝而非静默截断；不支持递归删除、目录打包下载、权限/所有者修改、跨卷复制和回收站。二进制文件可原样上传下载，不进入文本编辑器。符号链接和特殊文件仅展示，不提供跟随或修改入口。

## 数据安全边界

这里展示并直接修改应用正在使用的真实数据，不是快照或暂存。不要直接在线编辑数据库、数据库日志或其他由应用维护的二进制文件。删除不可恢复。建议先停相关业务并备份，不能把这个工具当一致性备份或数据库管理工具。

已有文件保存携带读取时SHA256，不匹配拒绝覆盖；新建和重命名拒绝覆盖已有目标。该保护只降低误覆盖风险，无法阻止业务进程同时写数据，不是跨进程事务或快照保证。

所有读写都要求服务器manage权限（卷列表的view权限不代表可以读取卷中秘密）。内容响应no-store，正文不记审计，不保存在网页全局状态或持久存储。卷内路径由Agent再次校验，不接受宿主绝对路径；拒绝根目录删除、路径回退、符号链接路径与特殊文件，文件写入拒绝多硬链接文件。

首批只支持Linux引擎上的普通local卷，不支持带自定义挂载选项的local卷、外部卷驱动、Windows卷。helper从引擎inspect取得卷的挂载点，仅将该卷目录bind挂入临时容器，不在Agent本地读取宿主路径，不接受用户指定宿主路径；缺失挂载点拒绝创建，避免浏览时自动新建空卷。不要与外部删除卷操作并发使用。受限helper不能绕过所有者权限，若卷文件只允许其他UID访问，可能返回权限错误，不自动chmod或chown。

Agent仅通过原有主动连接接受请求，不增加入站端口，不需要把宿主全部卷目录挂进Agent。文件操作由受限的临时helper容器执行，无网络、无docker.sock、删除额外能力、限制内存/CPU/PID，仅目标卷数据可持久变更。基础镜像alpine:3.20须已在所选服务器本地存在，缺失时先通过镜像拉取功能获取，不会静默联网拉取镜像。helper临时根文件系统可写以注入当前Agent程序，不应宣传为只读rootfs。

## 验收

- 243独立卷真实API：根目录列表、新建中文目录、新建文件、读取、SHA256匹配覆盖、重命名、删除文件/空目录通过。重复新建、旧哈希覆盖、非空目录删除、根删除、路径回退及绝对路径均被拒绝；卷外符号链接读取和多硬链接写入被拒绝。测试卷使用后删除，没有读取或改写业务卷。
- Linux：helperfs/runtime/handler全量及竞态检测通过；Hub卷文件授权与参数验证竞态测试通过。
- 浏览器：实际看到可点击卷名、进入独立文件页；在专用测试卷新建空文件成功，目录表格、文件读取、空文件编辑器、文本下载按钮可见。发现表格组件未注册并已修复；类型检查通过不代表真实渲染正确。
- 浏览器保存点击被扩展浮层阻挡，未完成浏览器保存落盘闭环；真实API保存及读取回验已通过，不将两者混同。浏览器上传/下载落盘、移动端及Podman仍待专项交互验收。
- helper容器请求结束清理验证通过；进程/宿主突然中断仍可能留下已打标签的临时容器，不承诺崩溃后的自动回收。
