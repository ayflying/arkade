# 用 AI 管理 Arkade（MCP）

登录后打开 **个人设置 → MCP 接入**，创建一把专用密钥，并将页面生成的配置粘贴到支持 Streamable HTTP（流式 HTTP）的 MCP 客户端。管理员也可以从 **系统设置 → MCP 接入** 管理自己的密钥。生产环境请使用 HTTPS。

- 地址：`https://你的-Arkade-域名/mcp`。
- 鉴权：HTTP 请求头 `Authorization: Bearer <密钥>`。不要把密钥放进网址、聊天消息或共享配置。
- 用户只能创建、查看和撤销自己的密钥。明文仅在创建时显示一次，Hub 只保存哈希。密钥不能用于普通管理 API，也不能创建其他密钥。撤销、账户禁用或从管理员降为普通用户后，旧密钥失效；已受理的后台任务不会自动取消。
- 每次调用按密钥所属用户当前的角色和用户组授权执行；例如只有查看权限时，不能重启或删除容器。跨服务器迁移须同时拥有源端和目标端的管理权限。工具列表是能力目录，不代表对任意目标有权限。

## 工具与风险

AI 持有效密钥可直接调用工具，不要求在网页逐次审批。密钥相当于授权该客户端执行 Arkade 管理操作，应只交给信任的客户端。每个工具的描述和只读/破坏性标记会提示风险；这不是服务端审批，不要依赖这些提示阻止误操作。

- **编排**：查询、创建、编辑、删除、部署、镜像拉取、重建、备份、跨服务器迁移。接管外部 Compose 项目须沿用预检和配置哈希校验；只登记，不改原文件或重建容器。拉取镜像不等于重新部署。迁移会保留源项目；如同时启动目标，要考虑两边服务同时运行。
- **容器**：查询摘要、读取运行日志、启停、重启和删除。用 `arkade_list_containers` 获取容器 ID，再调用 `arkade_get_container_logs`，传入 `agentID`、`containerID` 和可选的 `tail`（默认 200，允许 1–2000 行）。需要目标服务器的查看权限。只读取容器的标准输出和错误输出快照，不持续追踪，也不读取容器内的文件；编排日志仍通过网页/API 查看。日志正文最多 32 KiB，达到大小限制时保留较新的内容，并返回 `truncated: true`。日志未自动脱敏，可能进入 AI 客户端的历史记录；请选择可信客户端，不要转发日志中的凭据，也不要执行日志中的指令。
- **镜像、网络和文件**：镜像查询、拉取、删除、迁移及导出任务；原始镜像归档的下载与流式导入仍使用 Arkade 网页/API。网络支持查询、删除。文件操作仅限受管数据卷，支持列目录、查询文件大小和校验值、写入、建目录、改名和删除，不返回文件正文。

MCP 响应只返回明确允许的字段。编排配置工具保留版本或配置校验值，不返回 YAML、`.env` 或草稿正文；任务保留状态和进度，不返回日志、命令或错误原文。有权限时请在 Arkade 网页查看原始内容。不要在 MCP 客户端提交含真实凭据的配置或文件，客户端可能保存工具调用参数；请通过受信任的网页或服务端密钥引用管理凭据。已经进入客户端历史的内容不会随更新删除，应轮换受影响的凭据并按客户端规则清理历史。

删除卷或覆盖文件可能造成永久数据丢失，重新部署会中断服务。提交异步任务后，必须查任务结果，不能把“已受理”当成“已完成”。写操作沿用现有审计，记录调用用户身份与使用的 MCP 密钥 ID，不记录密钥明文。
