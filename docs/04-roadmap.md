# 04 路线图与交付缺口

更新日期：2026-11-09。本表区分源码完成、实际验收与尚未开发；单批测试通过不代表整个项目完成。

## 状态口径

- **已验证**：有相应真实环境证据，但只覆盖注明的范围。
- **待部署验收**：源码及本地测试通过，不能当作243已可用。
- **部分实现**：已有基础能力，但未达到完整规格。
- **未开发**：不能凭接口名、按钮或规划认定存在。
- **后置/待确认**：不是当前批次的开发承诺。

## 二、接下来必须补齐（主体功能）

### P0：已有反馈与部署验收

- [ ] 服务器列表真实添加按钮：预建Agent记录、生成专属接入密钥、显示待接入。
- [ ] Agent凭独立密钥绑定预建记录，不信任自行上报ID；旧共享凭据不可冒充专属记录。
- [ ] 密钥只生成时显示、服务端仅存摘要；支持重置并撤销旧凭据与连接。
- [ ] 部署引导提供环境变量注入的Compose与非敏感配置文件，不将密钥写进YAML或配置文件。
- [ ] 243恢复连接后，部署已提交的发现修复并核对实际5个Compose项目。
- [ ] 验证外部项目只读、停止项目可见、同名新建被拒且无文件/容器改动。
- [ ] 回归服务器管理、审计、概览、刷新开关与日志滚动行为。
- [ ] 清理本轮测试资源，仅保留用户要求保留的演示环境。

### P1：Compose项目完整性

- [x] 新建/编辑同时支持主Compose文件与可选`.env`。243真实API已验证创建/更新与容器插值；浏览器已确认区域，完整表单提交仍需人工复核。
- [x] `.env`同步、版本、联合哈希、删除/清空语义及Compose解析预检；支持有限KEY=value环境文件语法，不承诺完整dotenv变体。
- [x] 配置读取manage权限与no-store、不进入普通列表/详情；错误不回显.env原文。Hub数据库并非加密存储，部署者须保护数据库与备份；应用自身日志仍可能输出秘密。
- [ ] 支持服务`env_file`引用的文件，不能把它与Compose的`.env`插值混淆。
- [ ] 支持多文件覆盖、相对路径配置文件、secrets/configs引用；逐项声明边界。
- [ ] 备份可取回、可恢复，清楚区分配置备份与卷数据备份；有恢复测试才能算闭环。
- [ ] 外部项目导入预览、确认、来源标记与只读配置快照；不与原部署工具争写。
- [ ] 漂移差异对比、人工选择与回退；不得自动覆盖服务器上的修改。

### P2：单机管理缺口

- [ ] 容器详情（环境变量脱敏、挂载、端口、网络、健康状态）与资源监控。
- [ ] 评估容器创建、终端、文件操作等入口的实际必要范围，再开发；不擅自扩大。
- [ ] 镜像独立拉取、标签管理、导入导出。
- [ ] 网络与存储卷创建、详情及占用关系；危险删除的真实引擎测试。

### P3：原始需求尚未完成的主线

- [ ] 镜像仓库统一授权、多仓库、凭据安全分发及私有镜像拉取验收。
- [ ] 无外网场景的镜像同步。
- [ ] 跨服务器迁移预检：架构、磁盘、运行时、端口、路径与同名冲突。
- [ ] 停源服务、传输配置/镜像/卷、起目标、健康与数据校验。
- [ ] 断点续传、进度展示、失败回滚及源端显式清理。
- [ ] 直连/Hub中转传输，限额与中断处理。

## 三、后置及未确认范围

- 用户与用户组页面、组到服务器权限配置、完整权限验收：主体功能完成后统一做。
- 批量操作、定时备份/巡检、通知告警、Agent升级：原文为建议或后续项，先确认必要范围，不声称已交付。
- Kubernetes：当前不支持。用户已询问，尚未确定只读集群接入还是完整管理；需要单独规格，不可把K8s YAML交给Compose执行。
